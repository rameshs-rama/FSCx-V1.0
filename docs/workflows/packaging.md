# Packaging Workflow

## Primary flow

QC Released
→ Ready for Packaging
→ Pack-Out Check
→ Packed
→ Stores / Dispatch Ready

## Checkpoints

Confirm as relevant:

- correct product
- correct SKU
- correct brand/market pack
- correct accessories
- candles
- POSTreat
- tap
- stand
- manuals/inserts
- visible scratch/dent condition
- secure packing / immobilization
- carton/seal
- quantity packed

## Exceptions

Damage or incompleteness should create a clear exception/rework path rather than silently reducing quantity.

## Dashboard

Show:

- Ready to Pack
- Packed Today
- Blocked
- Damage/Rework
- Awaiting Stores Receipt / Dispatch Readiness
