## How Codex should use mockups

Treat screenshots as:

- information hierarchy reference
- workflow reference
- simplicity reference
- role/action reference

Do not treat them as pixel-perfect specifications if that makes the interface harder to use.

## UI correction notes from earlier mockups

- India should use RAMA brand context.
- UK/USA/France should use Phoenix brand context where applicable.
- Production entry should map to Production role rather than Stores by default.
- User Management department labels must match actual functional ownership.
- Factory users should not manually enter filter-set quantity.
- Single-entry and bulk-upload options should both be visible where relevant.
